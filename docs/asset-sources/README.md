# Asset Sources

This folder keeps source assets and license files away from the application root while preserving attribution material for the images used in `public/`.

- `auth-background/`: source image and license for `public/auth-bg.jpg`
- `landing-background/`: source image and license for `public/lowpoly-bg.jpg`

The app only loads optimized/static copies from `public/`. The files here are retained for project documentation and licensing context.
